# Stupiak's Local Print Connector v18

The Local Print Connector gives the Web app the same stable RAW TSPL output used by the Android APK.

A normal browser cannot open an arbitrary printer TCP 9100 socket. The Web app therefore sends the already-generated RAW TSPL document to this small local service, and the service opens the printer socket without using a browser print dialog, HTML page, driver scaling or Raster fallback.

## Supported routes

- **Web Direct Wi-Fi/LAN:** Web app → Local Connector → printer Raw TCP 9100 or LPR 515
- **PC/Mac Bridge RAW Queue:** Web/phone → Local Connector → installed Windows/CUPS RAW queue
- **Bridge Raw TCP:** Web/phone → Local Connector → printer TCP socket
- **Bridge LPR:** Web/phone → Local Connector → printer LPR queue
- Local network printer discovery

Every route receives the same Base64-encoded TSPL document generated by Stable TSPL Core v16.

## Windows

Requirements:

- Windows 10 or Windows 11
- Node.js 22 or newer
- Computer and printer on the same private network
- For RAW Queue mode, the target printer must already be installed in Windows

From PowerShell in the project folder:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-print-bridge-windows.ps1
```

The installer:

1. Copies the connector into `%LOCALAPPDATA%\StupiaksPrintBridge`.
2. Starts it automatically at Windows login.
3. Adds a Private-network firewall rule for TCP 8787 when permission allows.
4. Prints the Local Connector URL and pairing token.

For Web Direct Wi-Fi/LAN on the same computer:

1. Open **Label Printer Settings**.
2. Choose **Direct Wi-Fi/LAN**.
3. Enter the printer's own IP and port 9100.
4. Enter connector URL `http://127.0.0.1:8787`.
5. Enter the pairing token shown by the installer.
6. Press **Test route**, then **Test label**.
7. Save and choose **Use here**.

For an installed RAW printer queue, choose **PC/Mac Bridge → RAW Queue** and enter the exact queue name.

Remove the startup task:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-print-bridge-windows.ps1 -Remove
```

## macOS

Requirements:

- Node.js 22 or newer
- Mac and printer on the same private network
- For RAW Queue mode, the printer must already be installed in macOS/CUPS

From Terminal in the project folder:

```bash
bash scripts/install-print-bridge-macos.sh
```

The installer creates a LaunchAgent, starts the connector and shows its URL and pairing token. Use `http://127.0.0.1:8787` when the Web browser is running on that same Mac.

## Android native routes

Android does not need the connector for:

- **Direct Wi-Fi/LAN:** native Raw TCP or LPR to the printer's own IP
- **Bluetooth Classic:** native paired SPP connection

The Android APK and Web Direct LAN send the same TSPL bytes. Only the transport mechanism differs.

## Service endpoints

- `GET /health`
- `GET /printers`
- `GET /discover?port=9100`
- `POST /test`
- `POST /print`

All endpoints except `/health` require the pairing token. The service binds to port 8787 by default. Override it with `PRINT_BRIDGE_PORT`.

## Browser notes

- Chrome/Edge may ask for Local Network Access permission. Allow it for Stupiak's Ops.
- `http://127.0.0.1:8787` is recommended when the connector and browser run on the same computer.
- Do not expose port 8787 to the public internet.
- Web Food Labels intentionally do not use System/Browser Print because browser pagination and driver scaling caused labels to split across multiple stickers.
