## Known corrected mistakes

1. A temporary deployment helper used a top-level `return` in `node -e`, which Node 22 rejected with `Illegal return statement`. The corrected repository verifier uses normal module code and explicit exceptions/process exits.
2. An old Android workflow assertion checked stale source text. The 4.5.15 workflow checks the actual version contract and D1 Label runtime files.
3. The previous production deploy script automatically created resources and applied D1 migrations. It has been replaced by a no-migration, no-resource-creation verified deployment flow.
4. Earlier documentation incorrectly described Google Sheets as the global runtime source of truth. The canonical documentation now distinguishes D1 runtime state from remaining administrative Sheet/package content.
