# SP Label Printing V2 Mobile

Development-only mobile label printing v2 workspace.

Production printing app, production GAS, production Cloudflare deployment, and production label data are intentionally untouched.

Initial scope:
- mobile-first label workflow
- source batch selection/scanning
- source quantity consumption model
- FIFO validation contract
- expiry ceiling contract
- source-chain traceability
- stable printer transport adapter boundary
- local/mock backend until GAS V2 is designed later
